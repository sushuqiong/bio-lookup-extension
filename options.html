🧬 生信快查 · 设置

自定义数据库、页面浮层开关。所有设置只保存在本地浏览器（chrome.storage.local），不上传任何服务器。

页面浮层（双击选中文本弹出查询卡片）

开启后，在任意网页**双击**选中基因名 / rsID / 变异坐标，会在鼠标旁弹出小卡片，直接点库跳转。
首次开启需要授权「读取网页」权限（optional_host_permissions）；关闭开关即撤销注入。默认**不申请**该权限。

Zotero 联动（选中 PMID / DOI 时在本地 Zotero 库中查找）

需要 Zotero 7 正在运行，并在 Zotero 中勾选
设置 → 高级 → 允许其他应用与本机 Zotero 通讯（本地 API 端口 23119）。
开启后，选中 PMID: 12345678 或 DOI → 右键「📗 在 Zotero 中查找」→ 命中则直接跳转 Zotero 选中该条目。
插件不会上传任何数据，只访问本机 127.0.0.1。

右键菜单

本扩展的右键查询菜单在安装/更新扩展时自动创建。若你在网页上选中文本右键时看不到「生信快查」， 点下面的按钮重建一次即可（通常是浏览器回收后台服务或更新扩展后的偶发情况）。

添加自定义数据库

URL 模板里用 {q} 代表查询词（会自动 URL 编码）。例如：
https://my-lab.org/gene/{q} → 选中 TP53 时打开 https://my-lab.org/gene/TP53
按住 Ctrl/Cmd 可多选「适用类型」，不选则对所有类型生效。
